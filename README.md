# Паттерны проектирования на C# и .NET

Конспект паттернов проектирования и их применение на платформе .NET. 

Конспект собран в виде коротких глав с описанием задачи, структуры, преимуществ, ограничений и примеров из .NET.

Читайте книгу на сайте: [666mxvbee.github.io/DesignPatterns](https://666mxvbee.github.io/DesignPatterns/)

[Источник, откуда был сделан конспект](https://github.com/SergeyTeplyakov/DesignPatternsBook)
